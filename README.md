# MEGABOX · Empaques Corrugados

Sitio web de MEGABOX (Zapopan, Jalisco): cajas de cartón a la medida, láminas de corrugado (sencillo, doble y mullen) y serigrafía.

Es un sitio estático de un solo archivo (`index.html`), sin dependencias que instalar.

## Archivos

- `index.html`: el sitio completo.
- `404.html`: página de error personalizada.
- `robots.txt` y `sitemap.xml`: SEO. Reemplaza `TU-USUARIO` y `NOMBRE-DEL-REPOSITORIO` por tu URL real (o por tu dominio propio).
- `.nojekyll`: evita que GitHub Pages procese el sitio con Jekyll.

## Publicar con GitHub Pages

1. Sube estos archivos a la raíz de un repositorio público.
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main` y carpeta `/ (root)` → Save.
3. En uno o dos minutos el sitio queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.
4. Activa "Enforce HTTPS" en la misma pantalla.

## Importante

- No subas al repositorio tu constancia de situación fiscal ni otros documentos con datos personales (RFC, CURP). El `.gitignore` bloquea los PDF por si acaso.
- El registro de aceptación de términos y privacidad se guarda en el navegador del visitante y va dentro del mensaje de WhatsApp. Un sitio estático no puede guardar un registro propio en un servidor.
- Los textos legales son un borrador razonable, no asesoría legal. Revísalos con un abogado y completa o ajusta lo que haga falta.
